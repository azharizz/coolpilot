# COOLPilot

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React required by the user for a web interface. Python/OpenCV benchmark backend, SQLite, native ARM Docker. Backend choices delegated by the implementation request.

## Users

Computer-vision engineers evaluating configurations without breaking tracking or camera-health detection quality. Competition reviewers need inspectable evidence.

## Product Purpose

Run measured optimization experiments with a real agent, reject quality regressions, and select a validated workload configuration.

## Operating Context

Single operator on local ARM Docker first. Licensed AWS COOL/Graviton execution is a later deployment environment. User confirmed a browser app with real tracking benchmarks.

## Capabilities and Constraints

Annotated planar tracking plus timestamped camera-health replay code. Camera integration verification is pending at user request. The current Oxford fixture is development-only and cannot authorize apply. Nebius and optional Decisions credentials remain server-side. Every visible result must come from an experiment. Local results cannot be labelled COOL or Graviton results. No simulated production claims, automatic camera control or safety certification. Work solo. No em dashes.

## Product Principles

Evidence before recommendations. Quality gates are explicit. Rejected experiments remain inspectable. One click starts the real pipeline; advanced controls remain optional. Results precede supporting detail. Failure is visible and recoverable.

## Brand Commitments

Name: COOLPilot. OpenCV-inspired black, white and RGB visual system with Poppins. Compact, plain product language. Desktop is the current priority.
